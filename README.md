# Gravel Riot

Off-road truck racing on a volcano.

- **Play in your browser:** https://jakmartin13101.github.io/Racing-Game/
- **Windows download:** [GravelRiot-Setup.exe](https://github.com/jakmartin13101/Racing-Game/releases/latest/download/GravelRiot-Setup.exe)
  (Windows may warn that the installer isn't signed: click *More info*, then *Run anyway*)

No account needed for either. Both are rebuilt automatically by
[`.github/workflows/publish.yml`](.github/workflows/publish.yml) whenever the game changes.

The game's source, controls and build instructions are in [`game/`](game/README.md).
